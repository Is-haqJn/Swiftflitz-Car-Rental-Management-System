# PROJECT SCOPE & FEATURES

### SYSTEM OVERVIEW

The Swiftflitz Car Rental Management System will be a full-stack web application built using Laravel framework, providing comprehensive tools for managing your car rental business operations from end to end.

### PUBLIC WEBSITE

Vehicle Display & Catalog
- Comprehensive vehicle catalog with high-quality image galleries
- Detailed vehicle specifications (make, model, year, transmission, fuel type, seating capacity)
- Vehicle features and amenities display
- Flexible pricing display (can be shown or hidden per vehicle by admin)
- Real-time availability status
- Vehicle categorization (economy, luxury, SUV, etc.)
Search & Filtering
- Advanced search with multiple filter criteria
- Filter by vehicle type, price range, seating capacity, transmission type
- Date-based availability filtering
- Real-time filter results without page reload
- Sorting options (price, popularity, newest vehicles)
Dual Booking System
- Direct Booking (for vehicles with visible pricing): Full online booking with automatic cost calculation
- Quote Request (for vehicles without public pricing): Reservation request system
- Customer information collection (name, contact, email, license details)
- Date and time selection for pickup/return
- Airport pickup/drop-off options
- Automated email confirmations
- WhatsApp notifications to admin
Additional Pages
- About Us, Contact page with form
- Terms & Conditions, Privacy Policy
- FAQ section, Rental policies
- Customer testimonials, Newsletter subscription
- Fully responsive design (mobile, tablet, desktop)

### ADMINISTRATIVE PANEL

User Management & Access Control
- Role-based access control (RBAC) with custom roles
- Administrator role and extensible custom role creation
- Granular permissions for different system modules
- User activity logging for accountability
- Secure authentication with password requirements and reset functionality
Vehicle Management
- Complete vehicle inventory system with all specifications
- Multiple image upload and gallery management
- Flexible pricing configuration (daily, weekly, monthly rates)
- Toggle to show/hide pricing on public website
- Vehicle condition notes and maintenance history
- Insurance information storage
- Manual availability override for vehicle swaps


Rental Management
- Create new rentals with complete customer information
- Customer database with driver's license and ID details
- Rental details: pickup/return dates, locations, duration
- Pricing calculations with additional charges (insurance, extras)
- Deposit tracking and payment status management
- Vehicle condition documentation at pickup (photos, videos, mileage, fuel level)
- Manager assignment for accountability
- Rental agreement/contract generation

Rental Status Workflow
- Pending: Booking created but not confirmed
- Rented: Vehicle currently with customer
- Returned: Vehicle returned, pending admin approval
- Completed: Rental approved and closed after inspection
- Overdue: Vehicle not returned by expected date
Vehicle Return Process
- Return approval workflow requiring manager inspection
- Return condition documentation (mileage, fuel level comparison)
- Damage reporting with photo uploads and cost estimates
- Additional charges application (cleaning, damage, late fees)
- Automatic vehicle availability restoration upon approval
- Return inspection report generation
Dashboard & Reporting
- Real-time dashboard with key business metrics
- Fleet statistics (total vehicles, rented, available, overdue)
- Revenue analytics (daily, weekly, monthly)
- Manager performance reports and booking reviews
- Vehicle utilization and revenue per vehicle reports
- Financial reports (outstanding payments, deposits, repair costs)
- Customer rental history and repeat customer tracking
- Export functionality (PDF and Excel)
Notifications & Alerts
- Real-time notifications for new bookings and quote requests
- WhatsApp Business API integration for critical alerts
- Email notifications for confirmations and reminders
- Upcoming return reminders (24 hours before)
- Overdue rental alerts

- Maintenance requirement notifications
### TECHNICAL SPECIFICATIONS

- Backend Framework: Laravel (latest stable version)
- Database: MySQL
- Frontend: Modern responsive design with Vue.js/Blade
- File Storage: Support for images and video uploads
- Security: CSRF protection, SQL injection prevention, XSS protection, HTTPS enforcement
- Performance: Optimized queries, image optimization, caching implementation
- Integration: WhatsApp Business API, Email SMTP, Payment gateway ready
