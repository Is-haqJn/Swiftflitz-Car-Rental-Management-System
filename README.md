# Swiftflitz Car Rental Management System

A modern car rental management system built with a focus on efficiency and user experience.

## 🚀 Features

- Vehicle inventory management
- Rental booking system
- Customer management
- Real-time availability tracking
- Automated code formatting with GitHub Actions

## 📋 Prerequisites

- Node.js 18.x, 20.x, or 22.x
- npm or yarn package manager
- Git

## 🛠️ Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/Swiftflitz-Car-Rental-Management-System.git
cd Swiftflitz-Car-Rental-Management-System
```

### 2. Install dependencies

```bash
cd frontend
npm install
```

### 3. Run the development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```

## 📝 Available Scripts

In the `frontend` directory, you can run:

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run format:fix` - Auto-fix code formatting issues
- `npm run lint` - Run linter

## 🤝 Contributing

1. Fork the repository
2. Create your feature branch (`git checkout -b feature/AmazingFeature`)
3. Make your changes and commit (`git commit -m 'Add some AmazingFeature'`)
4. Keep your branch up to date with development:
   ```bash
   git fetch upstream
   git rebase upstream/development
   ```
5. Resolve any conflicts if they occur during rebase
6. Push to your branch (`git push origin feature/AmazingFeature`)
   > (optional) you can add `--force-with-lease` to safely overwrites your remote branch after rebase, but protects against accidentally deleting others' work
7. Open a Pull Request

**Note:** Always rebase your branch on the latest `development` before pushing to minimize merge conflicts.

Code formatting is automatically checked and fixed by GitHub Actions on push.
